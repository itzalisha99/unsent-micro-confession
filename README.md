A two-part micro-confession for the [make.fun bounty](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba): the message once typed to a human and never sent.

```
To: The teacher who believed in me
I never told you I dropped out the same week you wrote me that recommendation letter.
```

## Run

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` (120 characters, two lines).
`main.py` checks the entry against the bounty gate first: 1–260 characters
in total, exactly two lines, a `To:` line naming who it was meant for,
and a message of at most 200 characters on one line.
